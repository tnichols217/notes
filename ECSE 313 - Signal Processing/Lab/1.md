## 2.7 Sampling

Submit a hardcopy of the figure containing all four subplots. Discuss your results. How does the sampled version of the signal with $T_{s} = 1/10$ compare to those with $T_{s} = 1/3$, $T_{s} = 1/2$ and $T_{s} = 10/9$?

![[1/6_sampling_comparison.svg#inv_L]]

> [!answer]
> Below the Nyquist frequency, we lose the ability to accurately reconstruct the original $\sin$ frequency. The top two plots are above our Nyquist frequency and are thus easy to reconstruct the original signal. In the bottom left plot we appear to be sampling at exactly the same frequency as the signal itself, being half of the Nyquist, meaning you only see the peaks, troughs, and zeros of the signal itself. For the final plot, we are way below the Nyquist frequency, providing a poor mapping of the signal itself, making it appear to be a lower frequency when sampled.

`helpers.m`
```matlab
% A function to help set our defaults for all plots
function helpers = helpers(f)
    % Disables LaTeX rendering, as it is not supported by the export function well
    set(f,'defaultTextInterpreter','none')
    set(f,'defaultAxesTickLabelInterpreter','none')
    set(f,'defaultLegendInterpreter','none')
    % Increase Default font size
    defaultFontSize = 25;
    set(f, 'defaultTextFontSize', defaultFontSize);
    set(f, 'defaultAxesFontSize', defaultFontSize);
    set(f, 'defaultLegendFontSize', defaultFontSize);
    % Increase Canvas size
    f.Position(3) = 1000;
    f.Position(4) = 800;
    % Return our font size
    helpers = defaultFontSize;
end
```

% Define input functions and bounds
f1 = @(t) sin(5*t)^2;
f2 = @(t) exp(t);
bounds1 = [0, 2*pi];
bounds2 = [0, 1];

% Define riemann integral helper function
integ_helper = @(N, f, bounds) sum(arrayfun(f, linspace(bounds(1), bounds(2), N)))/N*(bounds(2)-bounds(1));
% Calculate riemann sum over increasing samples
integ_conv = @(N, f, bounds) arrayfun(@(n) integ_helper(n, f, bounds), linspace(1, N, N));

% Calculate riemann convergence for both functions
conv1 = integ_conv(100, f1, bounds1);
conv2 = integ_conv(100, f2, bounds2);

% Define functions asked for by questions (unused)
I = @(N) integ_helper(N, f1, bounds1);
J = @(N) integ_helper(N, f2, bounds2);

% Set up canvas
f = figure;
ff = helpers(f);
tiledlayout(2,1)

% Plot first function with riemann convergence
nexttile
plot(conv1)
axis padded
xlabel("Iterations (N)")
ylabel("Sum Value")
title("sin²(5t)")

% Same for second function

% Define signal1 given from assignment
function signal1 = signal1(t)
    signal1 = sin(t./pi) ./ (t ./ pi);
    signal1(t == 0) = 1;
end

% Define constants
bounds = 4*pi^2;
samples = 10000;

% Define domain and range
d = linspace(-bounds, bounds, samples);
vals = signal1(d);

% Riemann sum integrator
integ_helper = @(N, f, bounds) sum(arrayfun(f, linspace(bounds(1), bounds(2), N)))/N*(bounds(2)-bounds(1));

% Define energy function based on signal1
energy_func = @(t) signal1(t).^2;

% Calculate energy over time and energy total with riemann sun
energy_vals = energy_func(d);
energy_total = integ_helper(samples, energy_func, [-bounds, bounds]);

% Calculate min and max values
[ymax, imax] = max(vals);
[ymin, imin] = min(vals);

% Set up canvas
f = figure;
hold on
ff = helpers(f);

% Plot signal, min, max, energy
p1 = plot(d, vals);
p2 = plot(d(imax), ymax, 'ro', 'MarkerSize',8, 'LineWidth',2);
p3 = plot(d(imin), ymin, 'bo', 'MarkerSize',8, 'LineWidth',2);
p4 = plot(d, energy_vals);

% Set axes to be consistent with period
gca.FontSize = ff;
xticks(-4*pi^2:pi^2:4*pi^2)
xticklabels({'-4π²','-3π²','-2π²','-π²','0','π²','2π²','3π²','4π²'})

% Label all functions
legend( ...
    'signal1(t)', ...
    sprintf('Max = %.4f', ymax), ...
    sprintf('Min = %.4f', ymin), ...
    sprintf('Energy Total = %.4f', energy_total), ...
    Location='best', ...
    FontSize=ff )

xlabel("Time", FontSize=ff)
