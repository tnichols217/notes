## 16.5.4 Sharpening Exercise


![[1654_unsharp.svg#inv_L]]
Labeled Plot of Magnitude Response

![[1654_blur.png]]
Blur

![[1654_blur_sharp.png]]
Sharpened blurry image

> [!answer]
> $g(i,j) = \alpha f(i,j) - \beta [f(i,j) ** h(i,j)]$
> $G(\omega_1, \omega_2) = \alpha F(\omega_1, \omega_2) - \beta [F(\omega_1, \omega_2) \cdot H(\omega_1, \omega_2)]$
> $G(\omega_1, \omega_2) = F(\omega_1, \omega_2) \cdot [\alpha - \beta H(\omega_1, \omega_2)]$
> $\frac{G(\omega_1, \omega_2)}{F(\omega_1, \omega_2)} = \alpha - \beta H(\omega_1, \omega_2)$
> 
> This works due to the fact that convolution in the spatial domain becomes multiplication in the spatial-frequency domain. We also note that our analytical response fits this derivation directly.
> 
> It looks the most similar to a or b, which looks like the vertically flipped version of our low pass filter from the previous section. Our plot looks significantly more like a vertically flipped multivariate gaussian function as compared to the ones provided, which appear to be similar but with external rippling.
> 
> While the image looks like it may be sharper, it has an issue with "haloing" which is when the edges of objects look incorrectly lighter or darker than they should be. We also note that the edges of the image appear to be brighter than the rest, which we believe is due to the fact that there are no pixels around it to decrease its strength as those relevant pixels have negative values in our convolution matrix.
> 
> A bigger alpha and beta correspond with a greater sharpening effect of the output image, as we lean more on the central pixel instead of the gaussian.

`q1652.m`
```matlab
% Define out gaussian function
h = @(v) @(i) exp(- i^2 / 2 / v);
% Define the range to eval the gaussian given an N
r = @(N) (-(N-1)/2):1:((N-1)/2);
% Normalize matrix equation
nor = @(A) A / sum(A);
% Outer product of a vector
outer = @(A) A' * A;
% Out gaussian filter
gaussFilter = @(N, v) outer(nor(arrayfun(h(v), r(N))));
% Our median filter (performs a sliding window and takes median)
medianFilter = @(X, N) reshape(median(im2col(X, [N, N], 'sliding')), [size(X, 1) - N + 1, size(X, 2) - N + 1]);
% Our unsharp filter (a * impulse - b * gaussian)
unsharp = @(N, v, a, b)  a * padarray(1, [(N-1)/2, (N-1)/2]) - b * gaussFilter(N, v);

% Define variables we are using
N = 7;
variance = 1;
DFT_size = 32;
a = 5;
b = 4;

% Create our gaussian filter
h_matrix = gaussFilter(N, variance);
H = fftshift(fft2(h_matrix, DFT_size, DFT_size));
H_mag = abs(H);

omega = linspace(-pi, pi, DFT_size);
[W1, W2] = meshgrid(omega, omega);

% Plot its frequency response from -pi to pi
f = figure;
[ff, e] = helpers(f, w=2500, h=1200);

mesh(W1, W2, H_mag);
zlabel("Intensity");
title("Frequency response to Gaussian Filter");

% Export plot
e("plots/1652_fft.svg");

% Read input image
noise1 = imread("images/noise1.tif");
imwrite(noise1, "out_images/1652_race_noise1.png");

% Apply our filters
noise1_blur = uint8(filter2(h_matrix, noise1));
noise1_med = medianFilter(noise1, 3);

% Export images
imwrite(noise1_blur, "out_images/1652_race_noise1_blur.png");
imwrite(noise1_med, "out_images/1652_race_noise1_med.png");


% Read second image
noise2 = imread("images/noise2.tif");
imwrite(noise2, "out_images/1652_race_noise2.png");

% Apply filters again
noise2_blur = uint8(filter2(h_matrix, noise2));
noise2_med = medianFilter(noise2, 3);

% Export images
imwrite(noise2_blur, "out_images/1652_race_noise2_blur.png");
imwrite(noise2_med, "out_images/1652_race_noise2_med.png");


% Create our unsharp filter
h_matrix = unsharp(N, variance, a, b);
H = fftshift(fft2(h_matrix, DFT_size, DFT_size));
H_mag = abs(H);

omega = linspace(-pi, pi, DFT_size);
[W1, W2] = meshgrid(omega, omega);

% Plot the response of the unsharp filter
f = figure;
[ff, e] = helpers(f, w=2500, h=1200);

mesh(W1, W2, H_mag);
zlabel("Intensity");
title("Frequency response to Unsharp Filter");

% Export plot
e("plots/1654_unsharp.svg");

% Read input image
blur = imread("images/blur.tif");
imwrite(blur, "out_images/1654_blur.png");

% Apply filter
blur_sharp = uint8(filter2(h_matrix, blur));

% Export image
imwrite(blur_sharp, "out_images/1654_blur_sharp.png");
```
