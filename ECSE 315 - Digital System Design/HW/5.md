## 1

Find all of the essential prime implicants for the following Boolean functions.

### a

$F = y_{1}'(y_{0}'+x_{0} + x_{1}) + x_{1} (x_{0}+y_{0}')$

> [!answer]
> $= y_{1}'y_{0}'+y_{1}'x_{0} + y_{1}'x_{1} + x_{1}x_{0}+x_{1}y_{0}'$
> 
> ![[5/tables#^1at]]
> 
> All 5 of these terms are essential and cannot be expanded, therefore are prime implicants.
> 
> ![[5/tables#^1ap]]

### b

$F = x_{1}'x_{0}'y_{1}'y_{0}' + x_{1}' x_{0} y_{1}' y_{0} + x_{1} x_{0} y_{1} y_{0} +x_{1} x_{0}'y_{1} y_{0}'$

> [!answer]
> ![[5/tables#^1bt]]
> 
> By visual inspection, these are already essential prime implicants

### c

$F = w'x'z' + w'x'y + wxz + wx'y'$

> [!answer]
> 
> ![[5/tables#^1ct]]
> 
> From this we can see the first prime implicant is not prime, as $y'z'x'$ would cover the essential node from it.
> 
> We can also see that $y'zw$ can cover the other node of the fourth prime implicant.
> 
> Therefore, our only prime implicants are $w'x'y$ and $wxz$

### d

$F = y'z + wyz + w'(y' + z')$

> [!answer]
> ![[5/tables#^1dt]]
> 
> From the table, we can see that only $zw$ and $z'w'$ are prime implicents.

## 2

Using the tabulation method, find all the prime implicants for the following Boolean expressions.

### a

$F = w'x' + w'xy+wx + wx'y' + xy$

> [!answer]
> $F=\Sigma(0, 1, 3, 4, 6, 7)$
> 
> ![[5/tables#^2at]]
> 
> $w'$ and $y$ are essential prime implicants.

### b

$F = yz + w'z' + wy'z$

> [!answer]
> $F=\Sigma(0, 2, 3, 5, 7)$
> 
> ![[5/tables#^2bt]]
> 
> $w'z'+w'y+yz+wz$

### c

$F = x'y'z' + wy'z + xyz + w'yz'$

> [!answer]
> ![[5/tables#^2ct]]
> 
> $x'y'z'+w'x'z'+wz'y'+w'yz'+wy'z+w'xy+wxz+xyz$

### d

$F = wy'z' + wx'y' + wy + w'x'y'z + wxyz'$

> [!answer]
> ![[5/tables#^2dt]]
> 
> $wz'+wx'+x'y'z+wy$

### d

$F = \Sigma (0,2,4,5,10,11,13,15)$
