## 2

(True or False. Provide Explanation) IEEE 754 even has a symbol for the result of invalid operations, such as 0/0 or subtracting infinity from infinity. This symbol is NaN, for Not a Number. NaN has no usage in the programming and only causes error and should be avoided.

> [!answer]
> False, NaN is useful for writing resiliant code that can take into account errors and bad computations. While yes, you should typically avoid it if you mean to perform useful computation, it is a good indication a calculation went wrong when it does appear.
