# Assignment 3

HealthSense234.com receives raw nurse notes on a structured table, but the note text itself is free form (unstructured data). In this assignment, we will use a tiny dataset and a 3-term TF–IDF embedding (3D vectors) to illustrate vector search, then practice IVF/ANN indexing, and finally convert these nurse records to XML with a DTD.

```
Raw table: NurseNote(patient id, address, note text, visit date)

N1: (101, "Cleveland, OH", "child anxious after vaccination", 2025-02-12)
N2: (102, "Akron, OH", "persistent cough no fever", 2025-03-18)
N3: (103, "Columbus, OH", "vaccination follow-up mild fever", 2025-03-20)
```

For this assignment, we build 3D vectors using ONLY the following three terms (in this order):

$t_1$ = vaccination, $t_2$ = anxious, $t_3$ = cough.

TF (term frequency) is the raw count of the term in the note text. IDF uses log base 10:

$idf(t) = \log\left( \frac{N}{df(t)} \right)$

where $N$ is the number of documents $(= 3)$, and $df (t)$ (document frequency) is the number of documents containing the term at least once.

The TF–IDF vector for a document $d$ is defined as:

$v(d) = tf (t_{1}, d) \cdot idf (t_{1}), tf (t_{2}, d) \cdot idf (t_{2}), tf (t_{3}, d) \cdot idf (t_{3})$

## TF–IDF 3D Vectorization for Nurse Notes

### a

Compute $df (t_1)$, $df (t_{2})$, $df (t_{3})$ from the three notes, then compute $idf (t_{1})$, $idf (t_{2})$, $idf (t_{3})$.

> [!answer]
> $df(t_{1})=2$
> $df(t_{2})=1$
> $df(t_{3})=1$
> 
> $idf(t_{1})=\log(3/2)=0.17609125905568124$
> $idf(t_{2})=\log(3/1)=0.47712125471966244$
> $idf(t_{3})=\log(3/1)=0.47712125471966244$

### b

Compute the TF–IDF vector for each note N1, N2, N3 as a 3D vector (vaccination, anxious, cough).

> [!answer]
> $v(N1)=q=\langle0.17609125905568124, 0.47712125471966244, 0\rangle$
> $v(N1)=b=\langle0, 0, 0.47712125471966244\rangle$
> $v(N3)=a=\langle0.17609125905568124, 0, 0\rangle$

## Similarity Search with Euclidean and Cosine

Use your TF–IDF vectors from Q1. Let:

$q = v(N 1), a = v(N 3), b = v(N 2)$.

### a

Compute Euclidean distances $d(q, a)$, $d(q, b)$ and cosine similarities $cos(q, a)$, $cos(q, b)$. Which is closer to $q$ under each measure?

> [!answer]
> $d(q, a)=0.47712125471966244$ (one dimensional distance)
> $d(q, b)=\sqrt{0.17609125905568124^{2}+2\cdot0.47712125471966244^{2}}=0.6973503530696353$
> 
> By distance, $q$ is closer to $a$ than $b$
> 
> $\cos(q, a)=\frac{q\cdot a}{\|q\|\|a\|}=0.3462415530579614$
> $\cos(q, b)=\frac{q\cdot b}{\|q\|\|b\|}=0$ (there is no overlap)
> 
> By $\cos$ similarity, $q$ is still closer to $a$ than $b$

### b

A clinician issues a search query: “vaccination anxious”. Its 3D embedding (using the same TF–IDF scheme) is:

$v_{query} = (idf (vaccination), idf (anxious), 0)$

Rank the top-2 nearest notes among $\{N 1, N 2, N 3\}$ by Euclidean distance and cosine similarity. 

> [!answer]

> $\therefore$ $d(v_{query}, v(N1))=0$ and $\cos(v_{query}, v(N1))=1$
> 
> Out of $a$ and $b$, as in part a, $a$ is closest to $q$.

> N1 is closest, with a second of N3.

## XML & DTD for the SAME NurseNote data

Consider the XML fragment below:

```xml
<patient id="101">
	<address>Cleveland, OH</address>
	<visits>
		<visit date="2025-02-12">
			<note>child anxious after vaccination</note>
		</visit>
	</visits>
</patient>
```

And the DTD below:

```dtd
<!ELEMENT patient (address, visits)>
<!ATTLIST patient id ID #REQUIRED>
<!ELEMENT address (#PCDATA)>
<!ELEMENT visits (visit+)>
<!ELEMENT visit (note)>
<!ATTLIST visit date CDATA #REQUIRED>
<!ELEMENT note (#PCDATA)>
```

### a

Is the XML valid under this DTD?

> [!answer]
> Yes, the patient has exactly address and visits in that order, with the id tag.
> Address contains text only.
> Visits contain one visit, which is compliant.
> Each visit does have a date tag and a note within too, with only text within it.

### c

Write one query that computes cosine similarity between $v_{query} = (idf (vaccination), idf (anxious), 0)$ and each note vector, and returns the top-2 notes. (You may implement cosine in SQL directly: a sample code is provided for you to try below.)

```sql
WITH query_vec AS (
    SELECT
        0.1761::DOUBLE PRECISION AS q1,
        0.4771::DOUBLE PRECISION AS q2,
        0.0::DOUBLE PRECISION    AS q3
)
SELECT
    n.patient_id,
    (n.v1*q.q1 + n.v2*q.q2 + n.v3*q.q3) /
    (
        sqrt(n.v1*n.v1 + n.v2*n.v2 + n.v3*n.v3)
        *
        sqrt(q.q1*q.q1 + q.q2*q.q2 + q.q3*q.q3)
    ) AS cosine_sim
FROM NurseNoteVec n
CROSS JOIN query_vec q
ORDER BY cosine_sim DESC
LIMIT 2;
```

### d

Export patient 101’s record to XML in the structure of Q4 (SQL XML functions or Python is OK) and show validation result (Python lxml or an online validator).

SELECT
    xmlelement(
        NAME patient,
