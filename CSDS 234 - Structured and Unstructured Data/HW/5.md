```turtle
	rdfs:domain hs:ImageStudy ;
	rdfs:range xsd:string .
hs:medicationName rdf:type rdf:Property ;
	rdfs:domain hs:Medication ;
	rdfs:range xsd:string .
```

Write a SPARQL query for each of the following.

### 1

Find the names of all patients who have at least one nurse note.

```sparql
SELECT DISTINCT ?patientName
WHERE {
  ?p a hs:Patient ;
     hs:patientName ?patientName ;
     hs:hasEncounter ?e .
  ?e hs:hasNote ?n .
}
```

### 2

Find all nurse notes written on 2026-03-20, and return the patient name and note text.

```sparql
SELECT ?patientName ?noteText
WHERE {
  ?p hs:patientName ?patientName ;
     hs:hasEncounter ?e .
  ?e hs:hasNote ?n .
  ?n hs:noteDate "2026-03-20"^^xsd:date ;
     hs:noteText ?noteText .
}
```

### 3

Find all patients whose encounter has an image with finding “left opacity”.

```sparql
SELECT ?patientName
WHERE {
  ?p hs:patientName ?patientName ;
     hs:hasEncounter ?e .
  ?e hs:hasImage ?i .
  ?i hs:imageFinding "left opacity" .
}
```
